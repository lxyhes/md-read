## 本轮发现并修复

1. 导出脚注丢失正文及引用式图片漏收集：使用实际 Markdown AST、引用定义和脚注上下文，新增精确内容断言。
2. EPUB 目录过滤后目标编号错位、XHTML 不合法：先编号再过滤，通过 XML 序列化并严格检查包内各文件。
3. PNG 长图被 Chromium 视为受污染画布：使用自包含 SVG data URL。不能加载的图片明确报错，不生成漏图结果。
4. 导出使用旧文件、打印包含编辑界面：从当前草稿生成快照及独立打印页面，未保存内容也参与导出。
5. Windows PDF 引擎无法独占仍打开的临时文件、只读句柄无法同步：生成前释放句柄，输出后使用可写句柄同步并验证 PDF 文件签名，再提交到目标路径。实际中文、空格及 # 路径的 PDF 集成测试已通过，失败不覆盖原文件。

## 明确的验证边界

1. 桌面 DOCX/LaTeX 需要 Pandoc；浏览器 Word 回退支持常用公式，不能支持的结构报错，不偷偷退化为纯文本。Word 模板仅用于桌面 DOCX。
2. LaTeX 已检查原生转换、数学/脚注回读和图片相对路径；未通过 XeLaTeX 实际排版编译。DOCX/EPUB 已做结构和内容检查，未在全部 Word/电子书客户端做逐页视觉验收。
3. 内置测试浏览器没有返回 blob 下载文件路径。HTML/PNG 的实际生成及下载入口已检查，下载后的文件人工打开不冒充已验收。
4. 草稿在本地 localStorage，不是云备份或任意历史版本库。导出长图高度上限为 16000 像素；远程图片需先下载本地。EPUB 目录层级可选，但正文仍为单个 XHTML，不宣称分章拆文件。
5. 未替换或重启用户正在运行的旧版应用；交付重新构建的安装包。现有大体积构建分块提示仍存在，不等同于构建失败。
